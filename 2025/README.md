# BIORTC Nigeria 2025

This folder contains the 2025 BIORTC Nigeria Computational Neuroscience course materials.

## Structure

```text
2025/
├── BOOTCAMP/
├── Dandi/
├── Datasets/
├── Projects/
└── Workshops/
```

## Bootcamp

[`BOOTCAMP/`](BOOTCAMP/) contains the pre-course Python and data-science preparation material. It includes:

- Level 1 — algorithms and problem solving;
- Level 2 — Python coding basics;
- Level 3 — NumPy, pandas, and introductory data analysis.

## DANDI tutorial

[`Dandi/`](Dandi/) introduces the [DANDI Archive](https://dandiarchive.org/) and NWB-based neuroscience data access. It includes notebooks for browsing DANDI datasets and loading an example Drosophila attractor dataset.

## Datasets

[`Datasets/`](Datasets/) contains example datasets and notebooks used in the course, including human behavioural data from Stein et al. (2020).

## Workshops

[`Workshops/`](Workshops/) contains hands-on notebooks, slides, and supporting files for the 2025 workshops. Topics include:

- calcium imaging analysis;
- attractor models;
- recurrent neural networks;
- drift diffusion models;
- context-dependent decision-making / Mante data;
- integrate-and-fire models;
- machine learning for computational neuroscience;
- human behavioural data analysis;
- data visualisation;
- grant writing.

See [`Workshops/README.md`](Workshops/README.md) for the workshop index.

## Projects

[`Projects/`](Projects/) contains project options, notebooks, datasets, papers, and supporting resources for student projects.

## Notes

Most practical exercises are Jupyter notebooks (`.ipynb`). Open them with JupyterLab, Jupyter Notebook, VS Code, or Google Colab.
